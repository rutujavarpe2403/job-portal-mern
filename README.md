# Job Portal & Recruiting Management System

## About

A full-stack job portal and recruiting management system
built using the MERN stack.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Tailwind CSS

## Features

### Candidate
- Registration/Login
- Profile management
- Resume upload
- Job search
- Apply for jobs
- Track applications

### Recruiter
- Company profile
- Create jobs
- Update jobs
- Delete jobs
- View applicants
- Shortlist candidates
- Schedule interviews
- Update application status

### Admin
- Manage users
- Manage companies
- Manage jobs
- Dashboard
